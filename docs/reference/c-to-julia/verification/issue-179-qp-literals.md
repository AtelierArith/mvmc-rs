Owned test: `crates/mvmc-core/tests/mpi_issue179_qp_literals.rs`. Normal Cargo
tests need neither MPI nor C/Julia runtimes. No production implementation changes.
This is focused public-interface evidence, not full MPI, sampler or runner parity.

The original nine assertions are in
`extern/Julia-mVMC/MVMCOptimizers.jl/test_unit/test_unit_vmc_sampling_qp_split.jl`,

The complete source was read before porting. Julia uses one-based, end-exclusive
ranges; Rust uses zero-based, end-exclusive ranges. No fixture expectations are

Rust's local `calculate_ip_*` APIs do not accept an optional reduction keyword or
context. Its public sampling path requires a typed `&impl Reducer` and performs
group-only reduction through `sampling_sum_*`; it cannot request reduction with
a missing context. M1162 tests the actual public local-overlap plus explicit
`SingleProcessReducer` composition and the production sampling-log entry point.
M1161 is not counted as an executed equivalent error assertion. There are **eight
Rust tests**, not nine runtime tests or proof of all 170 parallel/MPI assertions.

C numerical authority is `extern/mVMC-1.3.0/src/mVMC/qp.c`, lines 89–127,
SHA-256 `ab53f8d929130bee4dbc88ba1b834d182eb65a6d70a3e5d2c51894020faf8e6f`,
and `qp_real.c`, lines 34–69, SHA-256
`eec104362f5540c368aed7e42403a79eeefc21a509da6c57c668b5c4fe887b71`.
C offsets weights by `qpStart` but receives compact PF buffers; Rust/Julia use
full buffers and range indices. The literal middle-range test deliberately
selects PF 11 with weight three, not C's compact-buffer indexing on a full buffer.
The real C path uses only each weight's real part. Both complex paths take the
complex logarithm directly. For the positive real overlap 47, Julia/Rust's
`abs(ip)+1e-100` log agrees numerically with the C log; this does **not** claim C
parity for zero/negative-overlap logarithms or silently repair that separate
historical port difference.

Computed nonzero overlaps and logarithms use explicit bounds of eight binary64
epsilons at the expected result's scale (at least one). Inputs involve at most
three small products/sums or one log; the bound allows direct math-provider
rounding, not a solver/trajectory tolerance. Empty ranges execute no arithmetic
and must return zero, allowing either zero sign. No computed floating bits are
compared.
