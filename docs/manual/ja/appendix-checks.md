# 付録: 引用のチェック方法

[目次](README.md) · 前へ: [11. 互換性と相違点](11-compatibility.md)

## A.1 引用のチェック

すべての「実装」ボックスには、C 関数と Rust 関数が `file:line` とともに列挙されています。これらが正確であることを保つため、

```bash
uv run --no-project scripts/check_manual_citations.py --c-root extern/mVMC-1.3.0
```

は `docs/manual/*.md` と `docs/manual/ja/*.md` を解析し、バッククォートで囲まれたすべての `path:line` または `path:line-line` の引用について、ファイルが存在し、その行がファイル内にあることを検証します。箇条書き
``- C: `symbol` — `path:line` `` および ``- Rust: `symbol` — `path:line` `` については、`symbol` の最初の識別子が引用された行に現れることも検証します。このスクリプトは任意の開発者向け
ツール(標準ライブラリのみ)であり、Rust のビルドやテストでは実行されません。`extern/mVMC-1.3.0` は git サブモジュールであり、チェックアウトしておく必要があります(または `--c-root` で渡します)。

執筆時点(リポジトリのコミット `3e9024ee`、C リファレンスのコミット `d73d06bd`)では、**430 件の引用をチェックし、問題は 0 件**と報告されました。その後チェッカーは `docs/manual/ja/` の日本語訳も対象とし、相対リンクと見出しアンカーも検証するようになりました。両言語を合わせた実行では 860 件(各言語 430 件)の引用をチェックし、問題は 0 件でした。

このチェックが対象としない事項: 引用された関数が隣接する式を本当に実装しているか、`driver.rs:271-278, 532-552` のように 1 つのバッククォート内に列挙された範囲、テスト名、演算順序に関する本文中の
主張。これらは、執筆時に C と Rust のソースを読んで確認しました。読解のみに基づく主張の箇所には **(コード読解)** または **(未検証)** と記してあります。
リファクタリングの後は、スクリプトを再実行して、ずれた行番号を更新してください(シンボル名が安定したキーです)。

## A.2 観測された出力の出所

すべての **(観測)** の記述と[チュートリアル](10-tutorial.md)の出力は、同一のビルドによるものです。

| 項目 | 値 |
|------|-------|
| リポジトリ | `AtelierArith/mvmc-rs`, `main` のコミット `3e9024ee` |
| ビルド | `cargo build --release -p mvmc-cli`(デフォルトフィーチャー。`mpi` なし) |
| プラットフォーム | Linux x86_64(`uname -sm`)、論理 CPU 36 個 |
| コンパイラ | `rustc 1.99.0 (b940084d7 2026-09-28)` |
| BLAS/LAPACK | システムの OpenBLAS 0.3.26(`libopenblas.so.0`)、デフォルトのスレッド設定 |
| 入力 | `benchmark/hubbard_chain/inputs/hubbard_chain_L16`(チュートリアルに示す `modpara.def` の変更を加えたもの) |

チュートリアルの数値は 1 つのビルドとプラットフォームでの結果です。他の BLAS プロバイダー、スレッド数、プラットフォームでは下位の桁が変わることがあり、メトロポリス判定を通じて後続のステップも変わりえます
([11.4](11-compatibility.md#114-数値比較ポリシー))。コマンドは(コミットされない)スクラッチディレクトリから実行しました。`output/` 以下のものはリポジトリの一部ではありません。

## A.3 未検証の事項

- MPI を必要とするすべてのもの: `mpi` フィーチャーのビルド、`mpirun` による起動、グループ実行(`NSplitSize > 1`)、集団的なエラー合意。[8.4](08-running.md#84-mpiとグループ実行)の記述は、コードと `crates/mvmc-core/src/run_mpi_tests.rs` のテストに基づきます。
- macOS での動作(Homebrew の OpenBLAS パス、FSZ リファレンス経路での Accelerate)。
- `mvmc-cli` での `simd-backend`(CLI が転送しない `pfapack` のフィーチャーです)。
- `crates/mvmc-cli/examples` のサンプルプログラム(`extern/Julia-mVMC` サブモジュールの入力が必要です)。
- FSZ/一般軌道、複素波動関数、RBM、OptTrans(`-o`)、`InterAll`、局在スピン、0 以外の `NExUpdatePath`、および 5 ステップのデモンストレーションを超える `NSRCG = 1` を用いた実行。
- C または Julia との数値の整合性に関するすべての実行。チュートリアルはリファレンスとの比較を一切行っていません。
- C mVMC の日本語マニュアル `extern/mVMC-1.3.0/doc/ja` は読んでいません。言い換えの元はすべて英語マニュアル(`doc/en`)です。
