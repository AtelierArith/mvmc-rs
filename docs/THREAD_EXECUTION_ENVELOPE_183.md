## Exact record validation

`exact_record_schema.py` requires complete strict settings, source/input hashes,
exact case and label inventories, source-derived scalar dimensions and matching
actual layout artifacts. Only inactive-real-buffer and zero-Green-count reasons
can permit dimension zero. Zero payload is exactly empty, not whitespace.
Active empty, wrong dimension, NaN/Inf, wrong label/case, stale source/input,
missing layout and changed launch seed fail closed. ShapeBound is structural
binding, never an independent numerical comparison.

Recorder emits actual borrowed layout, explicit Sfmt constructor/preparation
launch-seed binding and original retained SR dimension. `input_seed` remains
ModPara RndSeed, distinct from synthetic constructor override1. Disabled hooks
return before allocation/formatting. Parent adapter hash-checks each layout,
UUID/invocation/exact prefix, strict scalar settings and each child operand.
Schema adapter source has its own reviewed digest.

Inverse storage includes one pad entry per QP; full complex OO includes padded
trailing blocks; store buffers allocate even for NStore0. See external
`BUFFER_SOURCE_ANCHORS.md` for exact frozen source lines/hashes and equations.
