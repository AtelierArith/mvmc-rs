# Optional native initializer fixture tooling

Developer-only C-derived fixture conversion; Cargo never invokes or reads this
directory. The retained Perl generator consumes original native6-checkpoint
captures, definitions and independently hash-verified provenance archives. It
does not consume Rust expected outputs. --verify-only rejects incomplete cases,
incorrect source/runtime/provenance/input closures, malformed decimal/u32/u64
domains, unwritten flags and shape/layout mismatch. Output is exclusive-create.

Retained implementation is copied from qC04Mb. Complete acquisition environment,
source boundaries, GPL/BSD origins, compile/link commands and exact conversion
arguments are in [NATIVE-ACQUISITION.md](NATIVE-ACQUISITION.md). The optional
`reproduce-native-init.sh ORIGINAL_SOURCE ORIGINAL_BUILD FIXTURE_INPUTS NEW_OUT`
performs the reviewed six-hook extraction and init-stop build using an existing
bound original build; it does not rebuild or modify the vendored reference.
Its products require fresh prospective provenance, not reuse of historical
binary hashes. It is SOURCE documentation, not a newly executed acquisition.
No historical /tmp file is required for ordinary Rust tests. Original C source
and passive hook build/extraction SHA identities are documented in fixture
provenance.json and docs/reference/c-to-julia/verification/native13-initialization.md.
Generator/compiler runtime environments are developer dependencies only.

Historical generation BtspdP:13 JSON generated independently from C. Stronger
validate-generated iRz0EA independently verifies raw624/future624 CONTENT+order,
QP text, parameter decimal roundtrip and original definition full name/hash set.
Prior schema-only validation is not treated as full raw serialization proof.
No regeneration happened while preparing this candidate; all203 fixture/input
files were byte-compared with the retained independently validated static set.
