# Optional MPI SFMT state audit (#496)

These developer probes read all 624 SFMT19937 state words and the current word
index after a production calculation. State words and indices are integers;
their comparisons are exact. Floating-point output comparisons remain numerical
comparisons with explicit absolute/relative budgets. No Cargo build or Rust test
depends on this directory.

`c_rng_observer.c` is an independently written MPI observer, not extracted mVMC
source. It reads the unmodified executable's private ELF globals at
`MPI_Finalize`, after mVMC stops its All timer. It makes no RNG draws and changes
no mathematical operations. Initialization prints the MPI world and configured
OpenMP/BLAS thread counts. Do not combine it with another preload that overrides
`MPI_Init` or `MPI_Finalize`.

The C observer is deliberately tied to this Linux x86_64 executable:

* Upstream C commit: `d73d06bd529d3b2573f38eb5817c4a5f52971006`.
* Executable SHA-256: `6ae44625e227ccd6b9c38d2a7731fb445955108772e8741b452f70c6a641ac28`.
* Build: GCC 13.3, Release `-O3 -DNDEBUG -fopenmp`, MPICH 4.2.0,
  OpenBLAS 0.3.26 LP64; blocked Pfaffian updates disabled, GEMMT enabled.
* GNU `nm -S`: `idx` at `0x8555c0`, size 4; `sfmt` at `0x8555e0`, size 2496.
* `dl_iterate_phdr` supplies the PIE image base with ASLR enabled. Both globals
  must fall inside the writable main ELF segment; index must be in `[0,624]`.
* Origin of the audited state: `extern/mVMC-1.3.0/src/sfmt/SFMT.c`, SHA-256
  `b61f0f0239193fd4c06f2879e6e8452225bec45b3bca426902c244fd31ad4e3a`, and
  `SFMT.h`, SHA-256
  `4bea0eab7eb2fcfe197f73e1eca398b45eb316eb5fb77641546bc621893d17ae`.
  No source lines were extracted.

Verify the executable hash **before compiling and before launching**. A changed
executable requires reviewing and regenerating the offsets; the macro is an
explicit acknowledgement of that check, not a runtime hash verifier.

```sh
sha256sum "$c_binary"
nm -S "$c_binary" | rg ' (idx|sfmt)$'
/opt/mpich/bin/mpicc -std=c11 -O2 -Wall -Wextra -Werror -shared -fPIC \
  -fopenmp -DRNG_BINARY_OFFSETS_VERIFIED=1 \
  c_toolbox/mpi_rng_496/c_rng_observer.c -lopenblas -ldl -o "$observer"
mkdir -p "$audit_dir"
MVMC_RNG_AUDIT_DIR="$audit_dir" LD_PRELOAD="$observer" \
  OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=4 \
  /opt/mpich/bin/mpiexec -n 4 "$c_binary" namelist.def
```

`julia_rng_capture.jl` runs the normal Julia optimizer, then reads the existing
SFMT shared library's private state. It resolves offsets with GNU `nm -S`,
validates symbol sizes, anchors the library base to exported `gen_rand32`, and
records the actual library SHA-256 and offsets. It requires Linux ELF symbols
and a 624-word state. Run separately against the frozen baseline project and
the optimized project with the same inputs, seed convention, MPI world and
thread settings; neither result is an expectation generated by the other.

```sh
OPENBLAS_NUM_THREADS=1 JULIA_NUM_THREADS=4,0 JULIA_NUM_GC_THREADS=1 \
  JULIA_MVMC_INNER_THREADS=1 JULIA_MVMC_PFAPACK_THREADS=0 \
  UCX_ERROR_SIGNALS=SIGILL,SIGBUS,SIGFPE \
  /opt/mpich/bin/mpiexec -n 4 julia +1.13.1 --project="$reference_project" \
  c_toolbox/mpi_rng_496/julia_rng_capture.jl namelist.def "$audit_dir" 300
```

The audit output contains full state integers for each rank and normal optimizer
outputs. It is a separate correctness run, not primary benchmark timing.

Set `MVMC_RNG_AUDIT_COUNT=1` for the separate draw-count diagnostic. It replaces
only Julia wrappers, forwards each call to the same original native symbol,
and counts `gen_rand32` and `genrand_real2` as one 32-bit word each. The native
`SFMT-real.c` implements `genrand_real2` as `to_real2(gen_rand32())`.
The counter resets at each `init_gen_rand`; the audit also records every seed
and the preceding stream's count. Uncounted scalar and bulk native RNG
primitives throw rather than silently omit draws. Validate all 624 state words
and the index against an uninstrumented run before interpreting counts.
This optional wrapper instrumentation is excluded from performance timing.
