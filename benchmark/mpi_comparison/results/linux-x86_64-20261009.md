# Julia versus Rust MPI: Linux x86_64, 2026-10-09

Measured on AMD Ryzen 9 PRO 8945HS (8 cores / 16 logical CPUs) inside the maintained
Dev Container, with MPICH 4.2.0, one computation/BLAS thread per rank, 300 SR steps,
one full warmup and three measured repetitions per cell. All times below are medians.

## Fixed total samples per SR step

300 total samples: 300 per rank at MPI rank count 1, 75 per rank at rank count 4.

| Model | Rust 1 rank (s) | Rust 4 ranks (s) | Rust speedup | Julia 1 rank (s) | Julia 4 ranks (s) | Julia speedup | Julia/Rust at 4 ranks |
|---|---:|---:|---:|---:|---:|---:|---:|
| L16 | 3.098 | 0.967 | 3.20x | 4.226 | 1.723 | 2.45x | 1.78x |
| L24 | 6.448 | 2.027 | 3.18x | 8.895 | 3.476 | 2.56x | 1.71x |
| L32 | 11.938 | 3.849 | 3.10x | 15.685 | 5.932 | 2.64x | 1.54x |

## Fixed samples per rank

300 samples per rank: 300 total at one rank, 1,200 total at four ranks.
The identical one-rank baseline is reused from the fixed-total experiment.
Throughput gain is 4 × (one-rank time / four-rank time); total sample work increases fourfold.

| Model | Rust 4 ranks (s) | Julia 4 ranks (s) | Rust sample throughput gain | Julia sample throughput gain |

## Timing and numerical scope

Both workers time the production optimization API, using barriers before/after the call
and the maximum elapsed time across all ranks. Input parsing, allocation, initialization,
sampling, SR and output are included. Launcher startup, package setup and the warmup
(including first-call Julia JIT) are excluded. This is a single-host MPI measurement.
Both baselines use MPI even with one rank.

Inputs retain NSplitSize=1, NStore=1, NSRCG=0, RndSeed=1 and the reviewed Hubbard
definition files. Rank count changes independent chains/seeds, warmup work and
optimization trajectories. Sample throughput does not establish convergence quality
or effective independent sample count. Recorded energies are diagnostic, not a parity gate.
No numerical kernel, tolerance, reference fixture or RNG contract was changed.

Rust 1.99.0 uses release mode, thin LTO, one codegen unit and the C-order CPU backend.
Rust links system OpenBLAS 0.3.26 LP64. Julia 1.13.1 uses bundled OpenBLAS 0.3.30 ILP64
(Cooperlake dispatch), while its native PfaPack helper links system OpenBLAS 0.3.26.
The existing native helper was reused. The exact Rust binary, workers, MPICH tools/library,
Julia lock and native helper hashes were verified unchanged between sample policies.
